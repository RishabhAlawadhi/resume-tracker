# Resume Tracker (ATS-style Resume Analyzer)

A web app that analyzes a resume against a job description and provides:

- ATS match score out of 100  
- Matched keywords and skills  
- Missing skills and gaps  
- Suggestions to improve alignment with the target role  

---

## Tech Stack

- React (Vite)
- JavaScript (Keyword + NLP Matching)

---

## Features

- Role-based keyword matching (Software Engineer, Data Analyst, ML Intern)
- Instant scoring and resume feedback panel
- Clean UI for resume + job description comparison
